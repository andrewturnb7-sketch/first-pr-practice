# First PR Practice

A tiny practice project for learning how to submit a pull request on GitHub.

## What's here

- `greet.py` — a small function that returns a friendly greeting.
- `test_greet.py` — a couple of tests for it.

## Usage

```python
from greet import greet

print(greet("World"))
```

This will print `Hello, World!` to the console.

## Running the tests

```bash
python -m unittest test_greet.py
```

Contributions are welcome! This repo is meant for practicing your first pull reqeust.
